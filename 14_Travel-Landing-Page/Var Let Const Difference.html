Real-Life Example of var

“Suppose in a company project, one developer creates a variable using var for storing user data.
Later another developer accidentally redeclares the same variable in the same function.
Since var allows redeclaration, the old value gets overwritten and it may create bugs in the application.”

Simple Code Example

JavaScript
var user = "Kajal";

var user = "Rahul"; // accidentally redeclared

console.log(user);

How to Explain This Code

“Here the first value was ‘Kajal’, but another declaration changed it to ‘Rahul’.
Because var allows redeclaration, the original data can be overwritten accidentally.”

Short Interview Version ⭐

“In large projects, if multiple developers use the same variable name with var, the value can accidentally change because redeclaration is allowed. This may create unexpected bugs.”
